## 🎯 Принципы организации

### 1. Группировка по префиксам
Файлы сгруппированы по префиксам имени:
- `{handler_name}.go` - основной файл
- `{handler_name}_test.go` - тесты
- `test_*` - тестовые хелперы
- `*_helpers_test.go` - специализированные хелперы

### 2. Логическая структура
При просмотре в IDE файлы автоматически группируются:
```
auth*          - Auth handler
messenger*     - Messenger handler  
search*        - Search handler
websocket*     - WebSocket handler
handlers*      - Общие функции
router*        - Роутер
error*         - Обработка ошибок
test_*         - Тестовые хелперы
*_helpers*     - Специализированные хелперы
```

### 3. Go-идиоматичность
Все файлы находятся в одной директории `pkg/handlers/`, что соответствует стандартам Go.

## ⚠️ Почему не используются отдельные папки?

В Go файлы одного пакета **должны** находиться в одной директории. Создание отдельных папок потребовало бы:
- Отдельных пакетов для каждого хендлера
- Экспортирования всех общих функций
- Обновления всех импортов
- Усложнения без реальной пользы

Текущая организация через префиксы обеспечивает:
- ✅ Логическую группировку (файлы группируются по префиксам в IDE)
- ✅ Простоту навигации
- ✅ Соответствие стандартам Go
- ✅ Легкость поддержки
