### 6.1 Поиск сообщений

**Функциональность:**
- ✅ Поиск по содержимому сообщений
- ⚠️ Фильтрация по каналу, пользователю, дате
- ⚠️ Полнотекстовый поиск (FTS для SQLite)

**Endpoints:**
- `GET /search/messages` - поиск сообщений
  - Query параметры:
    - `q` - поисковый запрос (обязательный)
    - `workspace_id` - фильтр по workspace (опционально)
    - `channel_id` - фильтр по каналу (опционально)
    - `user_id` - фильтр по автору (опционально)
    - `from_date` - фильтр с даты (опционально)
    - `to_date` - фильтр до даты (опционально)
    - `page` - номер страницы (опционально, по умолчанию 1)
    - `limit` - количество результатов (опционально, по умолчанию 20)

**Реализация:**
- Использовать SQLite FTS (Full-Text Search) для быстрого поиска
- Или использовать LIKE для простого поиска (если FTS не настроен)
- Возвращать результаты с контекстом (несколько строк до/после найденного текста)
- Подсветка найденного текста в результатах

## Технические детали

### SQLite FTS (опционально)
Если нужен полнотекстовый поиск, можно использовать SQLite FTS:
```sql
CREATE VIRTUAL TABLE messages_fts USING fts5(content, message_id);
```

### Простой поиск (текущий подход)
Использовать LIKE для поиска:
```go
.Where(message.ContentContains(query))
```

### Структура результатов

**Сообщения:**
```go
type MessageSearchResult struct {
    MessageID   int64
    Content     string
    ChannelID   int64
    ChannelName string
    UserID      int
    UserName    string
    CreatedAt   time.Time
    Context     string // несколько строк до/после
}
```

**Пользователи:**
```go
type UserSearchResult struct {
    UserID   int
    Name     string
    Email    string
    AvatarURL string
}
```
