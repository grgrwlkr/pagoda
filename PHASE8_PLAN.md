## Технические детали

### Структура потока

```
Parent Message
├── Reply 1
├── Reply 2
│   └── Reply to Reply 2 (nested - опционально)
└── Reply 3
```

### Компоненты

**ThreadButton:**
- Кнопка "Ответить" под сообщением
- Показывает количество ответов
- При клике открывает форму ответа или разворачивает поток

**ThreadView:**
- Отображает родительское сообщение
- Список ответов под родительским сообщением
- Форма для добавления ответа

**ThreadReplies:**
- Компонент для отображения списка ответов
- Может быть встроен в сообщение или на отдельной странице
