# Project Documentation

This directory contains all project documentation organized by category.

## Structure

### 📊 [analysis/](./analysis/)
Analysis and research documents:
- `ALPINEJS_ANALYSIS.md` - Analysis of AlpineJS usage and replacement possibilities
- `DEVELOPMENT_GUIDE_VIOLATIONS.md` - Violations of development guide rules

### 📋 [reports/](./reports/)
Development phase reports and completion reports:
- Phase completion reports: `PHASE1_COMPLETE.md`, `PHASE2_COMPLETE.md`, etc.
- Final reports: `FINAL_STRUCTURE_REPORT.md`, `FINAL_TEST_REPORT.md`
- Refactoring reports: `REFACTORING_REPORT.md`, `REFACTORING_FINAL_REPORT.md`
- Testing reports: `TESTING_SUMMARY.md`, `TEST_STATUS_REPORT.md`
- Cleanup reports: `CLEANUP_COMPLETE.md`, `PAGODA_REMOVAL_COMPLETE.md`

### 📝 [plans/](./plans/)
Development plans and improvement plans:
- Phase plans: `PHASE5_PLAN.md`, `PHASE6_PLAN.md`, etc.
- Improvement plans: `IMPROVEMENT_PLAN.md`, `CHANGES.md`
- Testing plans: `TEST_COVERAGE_PLAN.md`
- Feature plans: `SLACK_DEVELOPMENT_PLAN.md`, `SLACK_TODO.md`

### 📖 [guides/](./guides/)
User guides and setup instructions:
- Quick start guides: `QUICK_START.md`, `SLACK_QUICK_START.md`
- Setup guides: `SEPARATION_GUIDE.md`, `SETUP_CHECK.md`
- Migration guides: `README_SEPARATION.md`, `ROOT_PATH_FIX.md`

### ✨ [features/](./features/)
Feature documentation:
- `THREAD_PANEL_FEATURE.md` - Thread panel feature documentation

## Main Documentation

The following documents remain in the project root for easy access:
- `README.md` - Project overview and getting started
- `DEVELOPMENT_GUIDE.md` - Development guidelines and best practices
- `ARCHITECTURE.md` - Project architecture documentation

## Navigation

Use this documentation structure to find information:
- **Starting development?** → Check `DEVELOPMENT_GUIDE.md` in root
- **Understanding architecture?** → Check `ARCHITECTURE.md` in root
- **Looking for analysis?** → Check `analysis/` directory
- **Need historical context?** → Check `reports/` directory
- **Planning new features?** → Check `plans/` directory
- **Setting up environment?** → Check `guides/` directory
- **Understanding features?** → Check `features/` directory
