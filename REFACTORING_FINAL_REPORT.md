## 🎯 Принципы организации

### 1. Группировка по префиксам
Все файлы сгруппированы по префиксам:
- `{handler_name}.go` - основной файл
- `{handler_name}_test.go` - тесты
- `test_*` - тестовые хелперы
- `*_helpers_test.go` - специализированные хелперы

### 2. Логическая структура
Файлы организованы логически:
```
auth*          - Auth handler
messenger*     - Messenger handler  
search*        - Search handler
websocket*     - WebSocket handler
handlers*      - Общие функции
router*        - Роутер
error*         - Обработка ошибок
test_*         - Тестовые хелперы
*_helpers*     - Специализированные хелперы
```

### 3. Go-идиоматичность
Все файлы находятся в одной директории `pkg/handlers/`, что соответствует стандартам Go (один пакет = одна директория).
